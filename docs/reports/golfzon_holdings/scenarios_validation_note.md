# 골프존홀딩스 소액주주 시나리오 분석 — 교차검증 노트

**검증대상:** minority_shareholder_scenarios.md (24행, 6시나리오+종합)
**검증기준:** 주입 증거풀 대조 / 2000자 이하

## 1. 사실 일치성 — PASS
공개매수가 6700원·57.5% 프리미엄·1차 미달 62.9%·2차 동일가 강행, 오너 지분(43.37%+10.65%, 파생 54.02%)·자사주 9.83% 제외·의결권 85.2%, 터톤캐피탈 2.6%·주주충실의무 위반, 카운티(장부 1886억·매각 2조 추정)·오너 귀속, 52주 신고가·외인 6일 순매수, 주총 배당 250원(4.7%) 가결 vs 1500원·소각 부결 등 핵심 수치가 증거풀과 정합. 날조 소지 없음.

## 2. 날조/지원 없는 주장 — CONDITIONAL
②시나리오의 "8/5 마감 2차 공개매수"는 증거풀상 1차 기한(6/29~8/5)에서 추론한 값으로, 2차 확정 마감일을 확증하는 팩트는 없음. 명백한 날조는 아니나 확정 사실처럼 서술된 점은 보완 필요(추론 표기 권고). 그 외 수치·사실은 모두 증거 기반.

## 3. 구조 완전성 — PASS
①시장매도 ②공개매수응모 ③비상장잔류 ④법적대응 ⑤주주권행사 ⑥관망배당 + 종합 최선안 구성 완비. 각 항목 전제/행동/기대효과/리스크/비판 5요소 일관 포함.

## 4. 비판 관점 균형 — PASS
소액주주 입장 70% 비중 기준 충족. 모든 비판이 근거 기반(오너 저가먹기 의심, 법적 승산 낮음, 의결권 85.2% 부결구조, 배당 4.7% 미흡 등)이며 근거 없는 정서적 비난 배제. 균형성 양호.

## 5. 실무 유용성 — PASS
주가>매수가 상황에서 시장매도 우위 논증이 타당하고, 각 시나리오별 출구·리스크가 개별주주 판단에 직접 활용 가능. 단 세금·수수료·유동성 슬리피지 고려는 미흡(경미).

## 6. 최종 판정 — CONDITIONAL (경미한 보완)
사실 일치성·구조·비판 균형·실무 유용성은 우수. 유일 보완점은 ②의 "8/5 마감"을 추론임을 명시할 것. 이외 날조 없음.

## 총평
본 보고서는 주입 증거풀과 높은 정합성을 보이며 6개 시나리오와 종합을 갖춘 구조적으로 완전한 산출물이다. 소액주주 비판 관점은 근거 기반으로 균형을 유지하고, 시장매도 최선안 논증도 실무적으로 유효하다. 다만 2차 공개매수 마감일(8/5)을 확정 팩트처럼 서술한 부분은 1차 기한 추론값이므로 각주·단서로 명확히 구분해야 한다. 해당 1건만 보완하면 실무 활용에 무방한 수준이다.
