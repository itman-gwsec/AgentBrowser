## 2. 날조/지원 없는 주장 — PASS (단, 1건 추론 명시 권장)
조작·지원 없는 수치는 없다. 다만 §3의 "장부가와 시장가의 극심한 괴리" 중 '시장가'는 증거가 준 2조원대 매각 거론(장부 1886억)에서 도출한 분석적 추론이며, 원문은 "거론된다" 수준이다. 분석문이 "의혹을 뒷받침한다"며 추론임을 전제하고 있어 날조는 아니다. 명시적 '추론' 태그 권장.

## 3. 구조 완전성 — PASS
